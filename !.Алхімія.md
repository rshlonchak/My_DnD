
# Обладнання алхіміка

| Обладнання           | Вартість обладнання | Вплив на складність створення |
| -------------------- | ------------------- | ----------------------------- |
| Набір алхіміка       | 15-25 зм            | +3                            |
| Невелика майстерня   | 100-250 зм          | 0                             |
| Приватна лабораторія | 600-1500 зм         | -3                            |
| Лабораторія майстра  | від 3000 зм         | -6                            |

#### Набір алхіміка. 
Три флакони або колби зі скла чи кераміки. Мірна ложка для точного дозування інгредієнтів. Скляна паличка для перемішування. Тримач для колб чи флаконів. Металевий казанок. Трубка для перегонки. Ступка з товкачиком. Фільтр або сито. Флакон спирту, флакон кислоти, коробочка залізної тирси, коробочка золи.  
#### Невелика майстерня. 
Все з набору алхіміка + наступне: Невеликий алхімічний стіл із вогнестійкою поверхнею Глиняна або чавунна пічка для повільного нагріву Кілька додаткових колб різної форми (груша, спіраль, крапля) Сушильна рамка для трав і грибів Прості ваги з гирями (грубі, не ювелірні) Грубий дистилятор Дерев’яна шафа з 10–20 баночками для трав і порошків Шкіряні мішечки з підписами Глиняні ємності для смол, жирів, воску Простий пісочний годинник Ганчір’я, щипці, захисні рукавиці  
#### Приватна лабораторія. 
Все з майстерні алхіміка + наступне: Повноцінний алхімічний верстак з кількома робочими зонами Перегінний апарат із мідною спіраллю Алхімічний тигель (витримує високі температури) Точні ваги ювелірної якості Охолоджувальна ванна для швидкого припинення реакцій Скляні трубки для керування парами й газами Алхімічна шафа з символами та замками Свинцеві контейнери для отрут Срібні або флакони з темного скла для активних настоянок Окреме сховище для летких і вибухонебезпечних речовин Магічні свічки або лампи з постійним полум’ям Захисні маски, фартух, рукави.  
#### Лабораторія майстра. 
Все з приватної лабораторії + наступне: Кілька спеціалізованих станцій: перегонка, ферментація, кристалізація, сублімація. Алхімічна піч з контрольованим магічним полум’ям Кристалічні або міфрилові тиглі Алхімічні лінзи для аналізу рідин Камера для роботи з газами і парами Крапельні дозатори Ізольовані кімнати для: отрут, нестабільних, еліксирів, експериментальних субстанцій. Контейнери з рунами збереження Повний алхімічний архів Камінь або коло для стабілізації магії Заклинання захисту, очищення, гасіння вибухів

  

# Створення та інтоксикація зілля

|   |   |   |   |   |
|---|---|---|---|---|
|Рідкість зілля (Потужність)|Складність створення|Мінімальний рівень навички (+3 за 1 різницю)|Час приготування|Інтоксикація|
|Звичайне|10|+2|2-3 дні|1|
|Незвичайне|13|+4|від 5 до 15 днів|2|
|Рідкісне|18|+6|від 2 до 6 тижнів|2|
|Дуже рідкісне|25|+8|від 7 тижнів|3|

Інтоксикація — це рівень отруєння організму зіллями та еліксирами. Максимально допустимий рівень інтоксикації визначається так: 

	3 + модифікатор Статури, але мінімум 2.  

Якщо рівень інтоксикації перевищує максимум, істота отримує стан Отруєний, один додатковий рівень втоми, а також кидає 1к8 на побічні ефекти.

| 1к8 | Побічні ефекти інтоксикації                                                          |
| --- | ------------------------------------------------------------------------------------ |
| 1   | Максимум здоров’я зменшено вдвічі                                                    |
| 2   | Перешкоди на рятівні кидки Статури                                                   |
| 3   | Втрата можливості використовувати реакції до довгого відпочинку                      |
| 4   | Втрата темного зору, а максимальна відстань звичайного зору зменшується до 6 метрів. |
| 5   | Зменшення переміщення вдвічі на одну годину                                          |
| 6   | Перешкоди на рятівні кидки Сили та Спритності                                        |
| 7   | Безсоння. Ефекти довгого відпочинку не застосовуються                                |
| 8   | Втрата комірки заклинань                                                             |

Щоб прибрати ці ефекти можна використовувати:

1. Заклинання Мале Відновлення — знімає 1 інтоксикацію, стан отруєний та знімає 1 позитивний ефект зілля, але не еліксиру.

2. Заклинання Вище Відновлення — знімає всі ефекти інтоксикації, всі рівні інтоксикації та всі позитивні ефекти від зілль та еліксирів.

3. Зробити довгий відпочинок.


# Спеціалізації


Цілюща алхімія - Лікування, відновлення, усунення хвороб

Бойова алхімія - Посилення зброї, вогняне дихання, захисні настійки

Трансмутаційна алхімія - Збільшення, зменшення, зміна форми

Алхімія посилення - Героїзм, сила, швидкість, витривалість

Алхімія отрут - Отрути, токсини, протиотрути

Містична алхімія - Рідкісні магічні ефекти, взаємодія з іншими планами
