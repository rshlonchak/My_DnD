
## Загальна інформація

На перший погляд це вишукана лютня з темного дерева, срібними струнами та оздоблена дивними вирізаними символами. Її звук настільки прекрасний, що навіть досвідчені музиканти не можуть пояснити, чому звичайні мелодії на ній звучать значно глибше й емоційніше. 

Замість відкритих угод він створив магічний інструмент, який сам укладав контракти з кожним музикантом.

Насправді ж це не просто музичний інструмент.

Лютня є [[Дияволи#Якір|якорем]], створеним могутнім дияволом **Варісом Моркентом. Через неї він поступово прив'язує до себе душу музиканта, а після його смерті безперешкодно забирає її до Пекла.

Проте сама душа — не головна мета.

Кожна зіграна мелодія живить Варіса людськими емоціями. Найціннішими для нього є:

- відчай;
- провина;
- ненависть;
- розпач;
- безумство.

Чим сильніше слухачі переживають ці почуття, тим більше сили отримує диявол.

## Прокляття

Після налаштування на лютню прокляття неможливо добровільно зняти.

Кожного разу, коли виконавець використовує її для виступу (не менше 5 хвилин), він непомітно віддає невелику частину власної душі.

Для смертного цей процес майже непомітний.
Спочатку це майже непомітно:
- музика стає дедалі красивішою;
- слухачі зачаровуються;
- сам музикант відчуває натхнення.

Але з часом людина:
- може забувати частину спогадів (так як лютня поглинає їх);
- починає відчувати емоції ніби через товсте скло;
- всі інші інструменти не звучатимуть вже нормально.

При тривалій грі іноді прокляття переходить на власника.

Проте після смерті власника його душа більше не належить природному порядку речей — вона переходить до Мальзарета.

## Механіка

Під час кожного виступу кинути **1d20**.

| d20      | Ефект                                                                                                                                                                                                                                                                                                                                                 |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1–5**  | **Ехо спогадів.** Один із присутніх (або сам виконавець, якщо слухачів немає) переживає яскравий спогад зі свого минулого. Спогад настільки реалістичний, що людина тимчасово перестає помічати навколишній світ.                                                                                                                                     |
| **6–15** | **Досконала мелодія.** Лютня звучить бездоганно. Ніяких додаткових ефектів не виникає.                                                                                                                                                                                                                                                                |
| 16-20    | **Плач душ.** Музика пробуджує приховані страхи, провину та втрати. Усі слухачі в радіусі 18 метрів повинні пройти ряткидок Мудрості (СК визначає Майстер). При провалі вони стають пригніченими, впадають в істерику, починають плакати, панікувати або переживати найболючіші моменти свого життя (ефект визначає Майстер відповідно до персонажа). |
